# IED Backup Manager v1.5.4

Data: 28/06/2026

## Resumo

Versao de manutencao com suporte a pacotes ABB PCM600 mais novos.

## Alteracoes

- Adicionado suporte a arquivos ABB PCM600 com extensao `.apcmp`.
- Mantido suporte existente a arquivos `.pcmp`.
- A leitura da versao continua usando `ProjectDataServer%versions.ini`.
- Atualizada a interface para exibir `ABB PCM600 (.pcmp, .apcmp)`.
- Atualizados testes e documentacao vigente para contemplar a nova extensao.

## Compatibilidade

- Mantem compatibilidade com backups PCM600 `.pcmp`.
- Nao altera o formato dos ZIPs.
- Nao altera as regras de versionamento `ATU`/`HIS`.
