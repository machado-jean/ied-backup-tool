# IED Backup Manager v1.10.1

Data: 05/07/2026

## Resumo

Patch de distribuicao para facilitar atualizacao pelos usuarios e permitir link
fixo de download do ultimo executavel publicado.

## Alteracoes

- O executavel distribuido passa a se chamar sempre `IED Backup Manager.exe`.
- A versao continua visivel dentro da interface, no titulo da janela e no splash
  screen.
- A pasta de release continua versionada em `releases/v1.10.1/`.
- O link direto para o ultimo executavel publicado pode ser fixo:
  `https://github.com/machado-jean/ied-backup-tool/releases/latest/download/IED%20Backup%20Manager.exe`.

## Compatibilidade

- Nao altera regras de backup, ATU/HIS, SHA256, tipos de IED ou `config.json`.
- Nao altera a checagem automatica de novas versoes.

## Arquivo

- `IED Backup Manager.exe`
