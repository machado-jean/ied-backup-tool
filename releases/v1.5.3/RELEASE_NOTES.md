# IED Backup Manager v1.5.3

Data: 27/06/2026

## Resumo

Versao de manutencao com aviso operacional para pastas sincronizadas.

## Alteracoes

- Adicionado aviso quando `ATU` ou `HIS` parecem estar dentro de pastas sincronizadas, como OneDrive, SharePoint, Dropbox, Google Drive ou iCloud.
- O aviso e informativo e nao bloqueia a execucao do backup.
- Atualizado o plano de melhorias para marcar o aviso de pastas sincronizadas como implementado.

## Compatibilidade

- Mantem compatibilidade com `config.json` existente.
- Nao altera o formato dos ZIPs.
- Nao altera as regras de versionamento `ATU`/`HIS`.

## Arquivo

- `IED Backup Manager v1.5.3.exe`
